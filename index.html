Altspace & Banter game

Tic-Tac-Toe

A synced multiplayer upright Tic-Tac-Toe board. Made for SideQuest / AltspaceVR worlds, and it also works in Banter.

There is no server: players stay in sync through the space's shared state, and the game is plain static files served from tic-tac-toe.firer.at.

Add it to an Altspace world

  • On the website: edit your world on altvr.app, open Snippets on the left, choose All, then pick Tic-Tac-Toe.
  • In Unity: add an empty GameObject, click Add Component > BS > Snippet and type tic-tac-toe.

Add it with a script tag

Paste this into a Banter space's HTML, or into an Altspace world's Assets/WebRoot/index.html (outside the snippet section). Give each copy its own instance to have more than one game in a space.

Script tag
<script src="https://tic-tac-toe.firer.at/TicTacToe.js" position="0 1.2 2" scale="1.5"></script>

All the settings are listed on GitHub.

A position of 0 0 0 means automatic: the turn sign sits in its default spot next to the board. Any other value places it relative to the board.

Features

  • Reset button
  • Several independent boards in one world
  • Built-in pieces or GLB models

How to play

  1. Click a square to take it.
  2. Three in a row wins.
  3. Reset clears the board for everyone.

Synced multiplayer upright Tic-Tac-Toe board with a reset button. Open tic-tac-toe.firer.at as a space in Altspace or Banter to try it.
